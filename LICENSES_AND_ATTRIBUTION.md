# Licenças e atribuição

## OpenStreetMap

Os dados cartográficos e footprints utilizados pela fonte OpenFreeMap são provenientes do OpenStreetMap. Preserve a atribuição exigida pelo OpenStreetMap/ODbL.

## OpenFreeMap / OpenMapTiles

A v0.3.2 usa o endpoint público de vector tiles do OpenFreeMap para visualização. A aplicação inclui atribuição na fonte MapLibre.

## Esri imagery

A camada de satélite utiliza World Imagery para o preview. Preserve a atribuição exibida pela aplicação e valide os termos aplicáveis antes de uma implantação comercial/contratual definitiva.

## Harpex Preview

Os dados procedimentais do modo Preview são gerados apenas para demonstração visual e não devem ser tratados como cadastro oficial.
